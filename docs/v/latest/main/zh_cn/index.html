      真理水晶

      古代咒法师遗留下的的遗物之一，便是这真理水晶。这些神秘的晶体似乎曾被用作测试工具——通过要求学徒生成特定的法术图案来评估其技艺水准。

      一枚真理水晶蕴含一个谜题,以及一个描述，还有限制提交图案列表的长度。有志的咒法师必须破解谜题，得到正确的图案列表


      要尝试解谜，请将真理水晶放入真理水晶基座，然后手持含有Iota的物品右键基座。水晶将评估你的法术并裁定结果。

      若验证通过，水晶将被消耗，并从该水晶对应的战利品表中发放奖励。

      追踪之眼

      追踪之眼会悬停在选定生物附近，像一只耐心的秃鹫一样如影随形。它不会自行碎裂——只是静静守望，直到目标消失。


      路标之眼

      路标之眼会飞向选定的地点并悬停在那里，标记该处。抵达后它会逗留片刻，然后化作一道光迸裂。


      召唤追踪之眼 (vector, entity →)

              被遗弃的卓伟之作

              前人有遗，后有来者。我既不是最初的咒法师，也不会是最后一个。

              在世界各地，分布着古老的咒法师们留下的遗迹。这些结构虽然被遗弃，被抛在凡世间，但仍旧折射出它们曾经被称为卓伟之作时的光辉与荣耀。


              古时候的咒法师似乎还会创造一种特殊的材料，用来测试学徒咒法的水平，如果能够通过考验，还能获得一定的奖赏。

              可惜我的资料对此记载还不够详尽，有机会的话，我应该进行一些更深入的研究。

                      探古寻迹 (vector, biome|structure →)

                      • 渲染方式
                        • 配色
                          浏览器不支持图案的可视化。图案代码见此：qqqqaqwawawww

                          接受一个群系Iota，召唤一枚飞向目标群系或结构的探古之眼，消耗一份充能紫水晶。


                          探古之眼

                          探古之眼像末影之眼一样被抛出后，会飞行一小段距离并悬停，随后搜寻周围区域。若感应到附近的目标群系或结构，它会转向指向目标。片刻之后它会碎裂——但更多时候会作为仍带着目标的物品掉落回来，可以再次抛出。


                          随缘之精思 (→ biome|structure)

                          • 渲染方式
                            • 配色
                              浏览器不支持图案的可视化。图案代码见此：wwwawaeqqqq

                              有半数概率随机挑选一个群系，另一半概率挑选一个结构，封装为Iota返回。与探古寻迹配合，可开启一场随缘的探索之旅。
