      真理水晶

      古代咒法师遗留下的的遗物之一，便是这真理水晶。这些神秘的晶体似乎曾被用作测试工具——通过要求学徒生成特定的法术图案来评估其技艺水准。

      一枚真理水晶蕴含一个谜题,以及一个描述，还有限制提交图案列表的长度。有志的咒法师必须破解谜题，得到正确的图案列表


      要尝试解谜，请将真理水晶放入真理水晶基座，然后手持含有Iota的物品右键基座。水晶将评估你的法术并裁定结果。

      若验证通过，水晶将被消耗，并从该水晶对应的战利品表中发放奖励。

      分合石

      普通的导向石每次只能挑出一条出路。但在研究了一些古代遗迹后，我发现媒质波完全可以同时沿多条路径并发前行——只要有一道足够清醒、又足够分裂的意志为它护航。

      可惜，普通的村民意识在分神两处时便已摇摇欲坠；唯有灾厄村民之中精于同时驱策多位仆从的存在，才足以承受这股撕扯。

      空白分合石

      以空白导向石为基底，嵌合绿宝石与充能紫水晶，便可制出空白分合石。

      潜行并使用物品/放置方块其任意一面，可将该面在未连接、输入与输出三态间切换。


      当媒质波进入空白分合石时，它将把当前栈与渡鸦之思复制给所有已连通的输出面，令多条分支真正并行推进；唯有全部活跃分支皆终结，促动石才会结束本次施法。

      若配置了多个输入面，先抵达的分支会在此驻留等待，直到所有输入面齐聚后再合并放行：栈按到达顺序自下而上拼接，渡鸦之思则以最后到达者为准。然而，若来自不同促动石的媒质波在同一分合石中相遇，冲突的波源将立即引爆事故！

      无石板媒质波

      为什么……我一次又一次完美地消灭了那些可憎的掠夺者，不留一个活口回去报信，可那令人作呕的号角声却总是在村庄边缘准时响起？

      虽然咒法学早已失落，但这群低等心智仍未忘却对媒质的本能运用：令媒质波在回环中往复震荡，借由空中的谐振越过旷野、将讯号传往另一座孤立的法阵。


      释出封于晶簇的圣灵，再把灾厄村民的意识剥离进法术环件……如此，让封闭彻底转为开放，无需石板便能直抵彼岸。

      拼合完第一组器件，一阵寒意刺穿脊背：它们的意识绝不自然——剥离进元件时竟然毫无违和，仿佛这群心智本就是为此而铸的零件。

      将一名袭击小队长的意识剥离进淬灵晶块中，制得灾厄发信器。


      灾厄发信器可六向贴面放置（潜行反向）。它串联在法术环中：媒质波穿过时，将当前栈与渡鸦之思向周围空间辐射，同时继续沿发信环传递。
      其辐射呈偶极子场型——沿旗杆轴向最弱，垂直旗面方向最强；半径为 8 + 6 × 已行石板数（上限 256 格）。空手使用物品/放置方块切换 0..15 频道，亦可用核心写入任意Iota作私有频道。

      媒质波中继器

      以山羊角为核心，辅以石板、充能紫水晶与淬灵晶碎片，便可合成媒质波中继器，用于跨越更远山海。


      媒质波中继器可正立或倒挂摆放，支持四向水平朝向。
      独立放置时，它会监听同频无线波，经 2 刻谐振后以号角前方 1.25× 的前向增益继续向外接力（等效石板数 +4，最低按 5 块起算，至多跨越 8 跳且绝不回环）。
      若将其直接串入石板环路，也能作为带前向增益的定向发信节点使用。

      将任意一名灾厄村民（掠夺者、卫道士、唤魔者或幻术师）的意识剥离到空白促动石中，便可制得掠夺者促动石。


      掠夺者促动石是一颗响应无线媒质波的促动石（带徽记一面为波流出口，有 1 秒冷却）。当同频脉冲抵达时，它将以发信端传来的栈与渡鸦之思作为首帧状态起振。

      只是有一点仍与设想不同：它跨过了发信与收信之间的石板荒漠，可接收端自身的法术环路仍须闭合回自身，方能顺利执行。


      媒质池

      纵使布局再精巧的卓伟法术环，往往也受限于促动石有限的媒质容量——每每未至终局便中途枯竭。

      若能以淬灵晶与石板构筑一口开放的蓄能石槽，将媒质之瓶的储流引入其中，或许就能在法阵运行途中随时为其补给，甚至回收余流。

      媒质池

      以媒质之瓶为核心，与淬灵晶碎片及石板围合砌成媒质池。


      媒质池仅能水平平放，最大可储存 7680 紫水晶粉（注入造物解除器则变为无限）。手持紫水晶粉、碎片、充能紫水晶或媒质之瓶等媒质容器使用物品/放置方块即可向池内注能；池中液面会随储量升降，接入红石比较器可输出 0~15 信号，佩戴探知透镜可察看准确余量。


      媒质池可作为串联节点接入法术环，媒质波穿过时会从栈顶弹出一个有限数值 n：

      n > 0：从池中取出 n 粉注入本环促动石（池内不足则引发事故）；

      n < 0：从促动石抽取 |n| 粉充入池中（促动石不足则引发事故）；

      n = 0：仅消耗该数值并继续传递；若栈空或栈顶非数值，同样触发事故。

      被遗弃的卓伟之作

      前人有遗，后有来者。我既不是最初的咒法师，也不会是最后一个。

      在世界各地，分布着古老的咒法师们留下的遗迹。这些结构虽然被遗弃，被抛在凡世间，但仍旧折射出它们曾经被称为卓伟之作时的光辉与荣耀。


      古时候的咒法师似乎还会创造一种特殊的材料，用来测试学徒咒法的水平，如果能够通过考验，还能获得一定的奖赏。

      可惜我的资料对此记载还不够详尽，有机会的话，我应该进行一些更深入的研究。

                          探古之眼

                          探古之眼像末影之眼一样被抛出后，会飞行一小段距离并悬停，随后搜寻周围区域。若感应到附近的目标群系或结构，它会转向指向目标。片刻之后它会碎裂——但更多时候会作为仍带着目标的物品掉落回来，可以再次抛出。
