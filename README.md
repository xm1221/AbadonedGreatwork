# Abadoned Greatwork

[![powered by hexdoc](https://img.shields.io/endpoint?url=https://hexxy.media/api/v0/badge/hexdoc?label=1)](https://github.com/hexdoc-dev/hexdoc)

Abadoned Greatwork addon for Hex Casting.

The `1.21` branch targets Minecraft 1.21.1 on Fabric and NeoForge. Hex Casting `0.12.0-devel-pre-68` and PAUCAL `0.7.1-pre-27` come from BlameJared CI. The other libraries are the 1.21.1 builds on Modrinth. IoticBlocks has no 1.21.1 file on Modrinth or CurseForge; NeoForge can use the optional `IoticBlocks1_21_1` fork, and the mod still loads without it.
